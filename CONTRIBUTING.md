# Contributing Guidelines

👋 Thanks for your interest in contributing!  
We welcome improvements, bug fixes, documentation updates, and new ideas.

---

## Ways You Can Contribute
- 🐛 Report bugs by opening an issue.  
- ✨ Suggest new features or enhancements.  
- 📝 Improve documentation (README, setup steps, examples).  
- 🎨 Refine UI/UX or design.  
- ✅ Add or improve tests.  

---

## Guidelines
- Keep changes focused and clear.  
- Write meaningful commit messages (e.g., `fix:`, `feat:`, `docs:`).  
- Be respectful and constructive in discussions.  

---

💡 If you’re unsure, feel free to open an issue and start a discussion.
